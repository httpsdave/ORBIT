# 🚀 ORBIT

**Organized Records for Better Institutional Tracking**

A web-based information system for managing student organizations at Laguna State Polytechnic University (LSPU). Built for the Office of Student Affairs and Services (OSAS).

## 📋 About

ORBIT digitizes student organization workflows—from recognition to activity reporting. 

**Key capabilities:**
- Digital submission of 10+ official LSPU-OSAS forms
- Real-time application tracking
- Activity report management (Financial, Narrative, Accomplishment)
- Organization roster management
- Archive system for historical data

---

## 🛠️ Tech Stack

**Backend:** Laravel 12, MySQL, DomPDF, PHPWord, TesseractOCR  
**Frontend:** Vue.js 3, Inertia.js 2, TailwindCSS 3, FullCalendar  
**Security:** Firebase Auth, 2FA (Google Authenticator)  
**Infrastructure:** Railway, Railway Volumes

---

## ✨ Features

- 📝 **Digital Forms**: 10+ official LSPU-OSAS forms with auto-save
- 👥 **Organization Management**: Member/officer rosters with photos
- 📊 **Activity Reports**: Upload and track three report types per activity
- 🔐 **Security**: Two-Factor Authentication, Firebase verification, role-based access
- 🗄️ **Archive System**: Academic year-end data preservation
- 🔔 **Notifications**: Real-time updates and system announcements
- 📱 **Responsive**: Desktop, tablet, and mobile support 
- 📄 **Export**: Generate PDF/DOCX documents
